# Awesome AI Tools

精选的 AI 工具列表，帮助您提高生产力（每个分类尽量只保留更成熟、口碑好、长期可用的选项）。

## 收录原则

* **优先保留**：效果稳定、用户基数大、持续更新、生态完善的工具
* **尽量不重复**：同类工具如果保留多个，会在描述里说明差异点
* **链接尽量用官网/主仓库**：减少第三方镜像/仿冒站带来的风险
* **面向生产力**：侧重能落地解决问题的产品

## AI大模型

* [ChatGPT](https://chatgpt.com/) — 通用对话式 AI 助手，覆盖写作、代码、图像与日常问题解决。
* [Claude](https://claude.ai/) — 偏强的写作/总结与代码协作体验，适合长文档处理与日常脑力工作。
* [Gemini](https://gemini.google.com/) — 多模态能力强，与 Google 生态（搜索、文档等）结合紧密。
* [Grok](https://grok.com/) — 偏“实时信息/热点”风格的助手，和 X 生态强绑定。

## AI搜索与研究

* [Perplexity](https://www.perplexity.ai/) — 检索增强（RAG）式搜索/研究助手，适合快速查资料与生成带来源总结。
* [NotebookLM](https://notebooklm.google/) — “基于你提供的资料”做总结/提炼/问答，适合做资料库学习与研究整理。
* [Elicit](https://elicit.com/) — 偏论文检索与证据整理，适合做研究问题拆解与文献综述初稿。
* [Consensus](https://consensus.app/) — 面向论文结论的问答与引用汇总，适合快速获取研究共识与关键证据。

## 写作与文档

* [Notion](https://www.notion.so/) — 笔记/知识库/协作一体化，AI 总结、改写与内容整理非常实用。
* [Microsoft 365 Copilot](https://www.microsoft.com/en-us/microsoft-365-copilot) — 深度集成 Word/Excel/PowerPoint/Outlook 的办公 AI（更适合重度 Office 用户/企业）。
* [Grammarly](https://www.grammarly.com/) — 英文写作润色与语气调整的“常青树”，适合邮件、报告、内容创作。
* [DeepL](https://www.deepl.com/) — 高质量翻译 + DeepL Write 润色，适合多语言沟通与专业文本优化。

## 演示与设计

* [Canva](https://www.canva.com/) — 设计 + 文案 + PPT 一站式，模板生态强，上手快、产出稳定。
* [Gamma](https://gamma.app/) — AI 驱动的演示/文档生成工具，适合把大纲快速变成可分享页面与幻灯。
* [Figma](https://www.figma.com/) — UI/产品设计协作标准工具，AI 能力逐步增强，适合团队级设计流程。

## 语音合成与配音

## 图片生成

**在线工具（即开即用）**

* [Midjourney](https://www.midjourney.com/) — 画面审美与风格化能力强，适合海报、概念图、灵感探索。
* [DALL·E（ChatGPT 内）](https://openai.com/dall-e) — 与对话式编辑结合紧密，适合“边聊边改”的出图流程。
* [Ideogram](https://ideogram.ai/) — 擅长生成带**清晰文字/排版**的图片（Logo、海报、标题图等）。
* [Adobe Firefly](https://www.adobe.com/products/firefly.html) — 与 Adobe 生态协同好，适合偏商业设计工作流与多工具联动。

**开源/本地工作流（可自部署，控制更细）**

* [ComfyUI](https://github.com/comfyanonymous/ComfyUI) — 节点式工作流，适合精细控制、可复用流程与批量生产。
* [stable-diffusion-webui（AUTOMATIC1111）](https://github.com/AUTOMATIC1111/stable-diffusion-webui) — 经典本地 WebUI，上手快、生态与扩展丰富。

## AI代码助手

**IDE / 编辑器**

* [Cursor](https://cursor.com/) — AI 原生代码编辑器，适合日常写代码、重构与理解大仓库。
* [Windsurf](https://windsurf.com/) — AI IDE 路线代表之一，强调“在 flow 中开发”的端到端体验。

**通用插件/助手**

* [GitHub Copilot](https://github.com/features/copilot) — 覆盖面最广的代码助手之一，适配主流 IDE 与 GitHub 工作流。

**终端 / Agent 型工具（更偏自动完成任务）**

* [Claude Code](https://claude.com/product/claude-code) — 终端/IDE 的代码 Agent，适合“让它直接改代码、跑命令、提 PR 级变更”。
* [Codex CLI](https://github.com/openai/codex) — OpenAI 的终端编码 Agent，适合本地仓库内的任务执行与变更生成。
* [Gemini CLI](https://github.com/google-gemini/gemini-cli) — 开源终端 Agent，适合喜欢可扩展/可集成工作流的开发者。

---
* [toprank](https://github.com/nowork-studio/toprank) — 开源（MIT）的 Claude Code SEO 与 Google Ads 插件，整合 Google Search Console、PageSpeed Insights 和 Google Ads API，可在终端中完成 SEO 分析和广告管理。


## AI应用开发平台

* [Dify](https://dify.ai/) — 开源 LLMOps / 应用平台，适合快速搭建、部署与运营 AI 应用（含 RAG、工作流等）。
* [Coze](https://www.coze.com/) — Bot/Agent 搭建与多渠道发布平台，上手快，适合偏“产品化交付”场景。
* [LlamaIndex](https://www.llamaindex.ai/) — RAG 连接数据源、构建索引与评测的常用框架组件。
* [LangChain](https://www.langchain.com/) — 生态最完整的 LLM 应用开发框架之一，组件多、集成广。

## 数据分析与BI

* [Julius AI](https://julius.ai/) — 面向个人/团队的“对话式数据分析”，适合表格到洞察的快速产出。
* [DataChat](https://datachat.ai/) — 对话式 BI/分析平台，偏业务用户自助分析与数据问答。
* [Tableau Pulse](https://www.tableau.com/products/tableau-pulse) — Tableau 的 AI 洞察与指标驱动体验，适合组织级指标追踪与解释。
* [Copilot for Power BI](https://learn.microsoft.com/en-us/power-bi/create-reports/copilot-introduction) — Power BI 生态内的 AI 分析/报告辅助，适合微软数据栈用户。
