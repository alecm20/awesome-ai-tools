## AI大模型

- [ChatGPT](https://chatgpt.com/) - 由 OpenAI 开发的对话式AI模型，能够进行自然语言交互、回答问题、生成文本等。
- [Gemini](https://gemini.google.com/) - Google 开发的多模态AI模型，能够理解和处理文本、代码、图片等多种信息。
- [Grok](https://grok.com/) - 由 xAI 开发的AI模型，能处理文本、代码等。
- [Claude](https://claude.ai/) - 由 Anthropic 开发的AI助手，代码生成效果不错。

## 图片生成

- [stable-diffusion-webui](https://github.com/AUTOMATIC1111/stable-diffusion-webui) - 一款开源的、功能丰富的Stable Diffusion图形化界面，支持多种功能和扩展。
- [Midjourney](https://www.midjourney.com/) - 一款流行的AI图像生成器，以其独特的艺术风格和高质量的图像输出而闻名。
- [Flux](https://bfl.ai/) - Black Forest Labs 推出的 AI 图像生成模型，包括一系列的高质量模型，推荐使用。

## 音乐生成

- [Suno](https://suno.ai/) - 一款领先的AI歌曲生成器，可以根据歌词和风格提示创作出完整的歌曲。


## 视频生成

- [Sora](https://openai.com/sora) - OpenAI开发的文生视频大模型，能够根据文本指令创建高质量、富有想象力的视频场景。
- [Kling](https://kling.kuaishou.com/) - 快手推出的文生视频大模型，效果不错。
- [Runway](https://runwayml.com/) - 一个功能强大的在线视频编辑和AI工具平台，提供多种AI视频生成和处理功能。
- [Pika](https://pika.art/) - 一款易于使用的AI视频生成工具，可以快速将文本或图片转换为视频。

## AI代码助手

- [Cursor](https://cursor.com/) - 一款专为AI辅助编程设计的编辑器，深度集成了代码生成、编辑和问答功能。
- [Claude Code](https://www.anthropic.com/claude-code) - Anthropic开发的命令行中使用的编程工具，效果比较好，但是 Token 消耗会比较快。
- [Windsurf](https://windsurf.com/) - AI IDE，和 Cursor 有点类似。


## AI应用开发平台

- [Dify](https://dify.ai/) - 一款开源的LLMOps平台，可以帮助开发者快速构建、部署和运营基于大语言模型的AI应用。
